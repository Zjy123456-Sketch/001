# SillyTavern 聊天记录瘦身

直接在酒馆里分析和优化正在玩的聊天。插件把瘦身结果保存回同一个存档，完成后可以继续聊。

## 安装

在 GitHub 仓库的 **Code** 菜单复制 HTTPS 地址。在 SillyTavern 的 **扩展 → 安装扩展** 粘贴地址并安装。扩展在运行酒馆的服务器上安装一次，同一账号用手机浏览器访问时也可以使用。

手动安装时，把完整的项目目录放到 SillyTavern 的 **data/<用户>/extensions/sillytavern-chat-optimizer/**，确保 manifest.json 在该目录的第一层。更新时用新版本覆盖该目录里的同名文件，再刷新酒馆。扩展无需构建或安装额外的服务端模块。

## 使用

1. 打开需要优化的聊天，从输入框旁的扩展菜单打开 **聊天记录瘦身**。插件会自动分析当前聊天。
2. 查看原始体积、优化后的预计体积和各字段占比。
3. 点击 **优化当前聊天**。显示保存成功后，关掉面板继续聊。

## 清理范围

- 只清理符合条件的小白盒 1.0 快照中重复的「压缩相邻消息」缓存。保留缓存变化节点、最新 8 个完整快照和全部楼层索引。
- 保留聊天正文、思考文本、候选回复、剧情摘要和当前变量。
- 分析在当前浏览器中进行。优化时通过酒馆自己的保存流程写回当前存档，再从当前酒馆服务校验该档。
- 小白盒配置或快照结构超出已验证范围时，界面只显示体积分析。
- 数字以存档 UTF-8 字节计量。原存档体积的字段统计含键和转义，剩余结构的开销列在「其他字段和格式开销」。
